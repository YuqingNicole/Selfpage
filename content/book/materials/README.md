# 《在平均答案之外》书稿素材区

这是一组待作者审阅的材料，不是定稿，也不是本人已完成的访谈。整理日期：2026-11-01。

## 先看哪里

- [两章审阅说明与待补采访](review-notes.md)：第一章如何修订，第二章如何展开，以及需要作者确认的真实经历。
- [Readings 章节映射](readings-map.md)：优先材料能改变哪一段论证，哪些可作为反例。
- [完整 40 条 Readings 索引](readings-index.md)：保留全部收藏入口；未读原文、访问失败与已核对的条目分别标注。
- [人物报道素材](people-materials.md)：公开报道中的选择与代价，附后续采访问题。

## 当前正文已吸收

第一章使用 Justin Yan 关于取消自动流程、改为主动决定何时启动的具名自述。

第二章使用北京日报的 AI 陪伴报道、数英的年轻设计师报道，以及 Readings 中 Emil Kowalski 将部分审美判断表达为条件规则的实践。

其余材料暂存，不因为收藏就视为背书，不把观点、预测、设想、本人经历和采访记录混为一谈。第三、四章尚未在本轮扩写；相应材料先留在映射中。

## 后续补充原则

每条材料尽量留下具体的人、当时真实存在的选择、付出的代价和后来怎样修正判断。旧报道标日期；没有追访就不补写后来的结局。未核对原文的线索不作为事实进入正文。涉及真实采访时，确认事实、匿名方式和引用许可。
