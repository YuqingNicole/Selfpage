# 投资学园 · 课程设计模板（steps 课程流）

样板：期权篇第 1 单元全部 3 课（`src/data/lesson-flows/u1l1.ts`–`u1l3.ts`）。同一单元的课程共用一个例子（XYZ 现价 $100、行权价 $100、权利金 $3/股），后一课直接接着前一课讲。

## 为什么改

旧版每节课 = 一墙知识卡片（比喻 + 4 条要点）+ 5–6 道题，题型顺序几乎固定。
学习者先被动阅读、再被测验，像课本加习题册，学到第三课就知道下一题是什么。

新版用 `lesson.steps` 把讲解和练习交错起来：**先让人做，再给名字**。

## 一节课的骨架（约 12–15 步，3–4 分钟）

| 段落 | 作用 | 常用步骤 |
| --- | --- | --- |
| 1. 难题 | 用一个具体决策开场，不先给定义 | `concept` |
| 2. 先算 | 让学习者凭直觉算出答案，再揭晓概念 | `choice` |
| 3. 起名 | 把刚算出的东西对上术语，一次最多 4 个 | `concept` + `bullets` |
| 4. 变式 | 同一个例子换一个结局，检验理解而非记忆 | `choice` / `tf` |
| 5. 动手 | 拖动损益图，亲眼看到形状 | `slider` · `explore` |
| 6. 预测 | 先落点猜测，再揭晓曲线 | `slider` · `target` |
| 7. 换视角 | 站到交易对手一侧，同一笔交易再算一遍 | `concept` + `choice` |
| 8. 迁移 | 用镜像概念（Call → Put）检验能否举一反三 | `concept` + `choice` |
| 9. 巩固 | 把本课要素放在一起 | `match` |
| 10. 收束 | 四句话总结 + 下一课预告 | `concept` + `bullets` + `footer` |

## 规则

- **一个例子贯穿全课。** 数字从头到尾不换（例：现价 $100、行权价 $100、权利金 $3/股），学习者的注意力留给概念，而不是重新读题。
- **一步只讲一个点。** `concept` 正文控制在 2–3 句；需要列表就用 `bullets`，不超过 4 条。
- **先做后讲。** 新术语第一次出现前，至少有一道题让学习者先用直觉碰到它。
- **每课至少一个互动步骤。** 有损益关系的课用 `slider`；`explore` 必须设置 `visit`，确保学习者真的拖过两侧。
- **讲解写在反馈里。** `explain` 要说清「为什么」并带上具体数字，不只是复述正确答案。
- **干扰项要像真实误解**（例：把 Call 卖方亏损算成 −$3,000，忘了扣掉收到的权利金），不要用搞笑选项凑数。
- **`exercises` 仍保留。** 它是 Boss 战和分级测试的题库；`steps` 只用于课程闯关。

## 技术备注

- 步骤类型：经典题型（`choice` / `tf` / `fill` / `match`）+ `concept` + `slider`，定义在 `src/data/optionsCourse.ts`。
- `display`（`concept` / `choice` 可用）：等宽展示卡，适合一行报价、一个公式；题目可以直接指着它问。
- `slider.refLine`：额外参考竖线，股票、期货这类没有行权价的仓位用它标出买入价。
- `concept` 与 `slider explore` 不计分、不扣红心；正确率只按计分步骤计算。
- 错题本只收录 `steps` 中的经典题型，key 为 `lessonId:f{index}`。
- 新课程流写在 `src/data/lesson-flows/<lessonId>.ts`，中英文各导出一份，分别挂到中文课程数据和 `options-course-en-parts`。
