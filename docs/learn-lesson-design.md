# 投资学园 · 课程设计模板（steps 课程流）

已完成：期权篇第 1–4 单元（`src/data/lesson-flows/u1l*.ts`–`u4l*.ts`）。

同一单元的课程共用一个例子，后一课直接接着前一课讲：
- 第 1 单元：XYZ 现价 $100，行权价 $100 的 Call，权利金 $3/股
- 第 2 单元：XYZ 现价 $100，$105 Call（$2）与 $95 Put（$3）；前两课站在买方，第 3 课站在卖方，交易的是同两张合约。共用数据在 `u2-shared.ts`
- 第 3 单元：XYZ 现价 $100，30 天后到期的 $100 Call，隐含波动率 25%（Black-Scholes 算出 ≈ $3.02，与前两单元的 $3 对上）。课文里引用的价格都用同一个引擎算，和互动图显示的一致
- 第 4 单元：沿用第 3 单元的合约（$100 Call $3.02、Put $2.69）。对照组 ABC 用 IV 50%（$5.87）；财报场景 IV 60% → 25%；平价的 $0.33 来自行权价现值 $99.67（利率 4%）

## 为什么改

旧版每节课 = 一墙知识卡片（比喻 + 4 条要点）+ 5–6 道题，题型顺序几乎固定。
学习者先被动阅读、再被测验，像课本加习题册，学到第三课就知道下一题是什么。

新版用 `lesson.steps` 把讲解和练习交错起来：**先让人做，再给名字**。

## 一节课的骨架（约 12–15 步，3–4 分钟）

| 段落 | 作用 | 常用步骤 |
| --- | --- | --- |
| 1. 难题 | 用一个具体决策开场，不先给定义 | `concept` |
| 2. 先算 | 让学习者凭直觉算出答案，再揭晓概念 | `choice` |
| 3. 起名 | 把刚算出的东西对上术语，一次最多 4 个 | `concept` + `bullets` |
| 4. 变式 | 同一个例子换一个结局，检验理解而非记忆 | `choice` / `tf` |
| 5. 动手 | 拖动损益图，亲眼看到形状 | `slider` · `explore` |
| 6. 预测 | 先落点猜测，再揭晓曲线 | `slider` · `target` |
| 7. 换视角 | 站到交易对手一侧，同一笔交易再算一遍 | `concept` + `choice` |
| 8. 迁移 | 用镜像概念（Call → Put）检验能否举一反三 | `concept` + `choice` |
| 9. 巩固 | 把本课要素放在一起 | `match` / `shape` |
| 10. 收束 | 四句话总结 + 下一课预告 | `concept` + `bullets` + `footer` |

## 规则

- **一个例子贯穿全课。** 数字从头到尾不换（例：现价 $100、行权价 $100、权利金 $3/股），学习者的注意力留给概念，而不是重新读题。
- **一步只讲一个点。** `concept` 正文控制在 2–3 句；需要列表就用 `bullets`，不超过 4 条。
- **先做后讲。** 新术语第一次出现前，至少有一道题让学习者先用直觉碰到它。
- **每课至少一个互动步骤。** 有损益关系的课用 `slider`；`explore` 必须设置 `visit`，确保学习者真的拖过两侧。
- **讲解写在反馈里。** `explain` 要说清「为什么」并带上具体数字，不只是复述正确答案。
- **干扰项要像真实误解**（例：把 Call 卖方亏损算成 −$3,000，忘了扣掉收到的权利金），不要用搞笑选项凑数。
- **配对题两边的文字尽量不要重复。** 组件已经支持重复（同文字卡片可互换），但重复会让题目变得含糊；需要表达同一状态时，把具体结果写进去（如「每股赚 $10（实值）」）。
- **`exercises` 仍保留。** 它是 Boss 战和分级测试的题库；`steps` 只用于课程闯关。

## 技术备注

- 步骤类型：经典题型（`choice` / `tf` / `fill` / `match`）+ `concept` + `slider`，定义在 `src/data/optionsCourse.ts`。
- `display`（`concept` / `choice` 可用）：等宽展示卡，适合一行报价、一个公式；题目可以直接指着它问。
- `shape`：四张迷你损益图选一张（每张图各自缩放纵轴，比的是形状），作答后揭晓名字。适合先凭直觉猜形状、再用滑块验证。
- `value`：到期前的价格（Black-Scholes）= 内在价值 + 时间价值。可拖股价、剩余天数或两者；横轴可选股价（看时间价值在哪最厚）或剩余天数（看时间衰减加速）。`showSplit: false` 可先只看价格和实值/虚值状态。`ivRange` 加一个 IV 滑块；`compare: 'both'` 并排显示同行权价 Call 与 Put，`'parity'` 再加 Put-Call 平价读数；`target.live` 让反推类题目（调 IV 对上报价）在作答时就能看到读数。
- `slider.refLine`：额外参考竖线，股票、期货这类没有行权价的仓位用它标出买入价。
- `concept` 与 `slider explore` 不计分、不扣红心；正确率只按计分步骤计算。
- 错题本只收录 `steps` 中的经典题型，key 为 `lessonId:f{index}`。
- 新课程流写在 `src/data/lesson-flows/<lessonId>.ts`，中英文各导出一份，分别挂到中文课程数据和 `options-course-en-parts`。

## 投资主线（/learn/investing）

已完成：L1「看懂市场语言」第 1–4 单元、L2「看懂公司」第 5–8 单元（`src/data/lesson-flows/i1l*.ts`–`i8l*.ts`），中英文分别挂到 `investCourse.ts` 和 `investCourseEn.ts`。

- **保留这条主线的原则：每道题嵌在真实公司、真实数据、真实时间点里。** 数字为历史近似值，在课文里标「约」。
- 每个单元用一家公司贯穿：第 1 单元苹果（拆股、市值、回购）；第 2 单元苹果 FY2023 利润表（硬件 vs 服务毛利率），亚马逊和 Costco 作对照；第 3 单元亚马逊（利润 vs 现金、自由现金流、AI Capex）；第 4 单元 2020–2023 年的利率周期。
- L2「看懂公司」第 5–8 单元（`i5l*.ts`–`i8l*.ts`）：第 5 单元 Netflix（收入原型 → 单位经济 LTV/CAC → 定价权即护城河）；第 6 单元苹果 iPhone（量价拆解 → 智能手机 S 曲线），第 3 课亚马逊 AWS 首次披露；第 7 单元每课一个行业（订阅 NRR、连锁餐饮同店、美光周期）；第 8 单元管理层（英伟达指引、苹果停止披露销量、SMCI 审计师辞任）。第 8 单元第 2 课练的是读文字，没有计算器，用 `choice.display` 放一段电话会问答。
- 互动题用 `calc`（计算器）：输入滑块 + 实时输出，输出的计算和格式化写成函数（所以只能放在 TS 数据里）。`target` + `hideOutputs` 适合「先心算、再揭晓」；拖一个「你的答案」滑块也可以当数值题用。金额格式化用 `lesson-flows/fmt.ts`（中文用亿 / 万亿，英文用 B / T）。
- 投资主线原有的「🌱 简单题」开关只替换旧版题目；已改成 `steps` 的课程不受影响（新版课程本身就是从直觉题开始的）。
