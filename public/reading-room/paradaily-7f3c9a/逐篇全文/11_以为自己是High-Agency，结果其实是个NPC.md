# 11. 以为自己是High-Agency，结果其实是个NPC

## 内容摘要

文章借 high-agency、NPC、永久底层、996 和 taste 等词剖析硅谷的 AI 地位焦虑。它将能动性解释为自主设定目标与克服障碍的能力，质疑用过度工作和品味表演证明身份，并强调真实判断来自长期学习、练习与经验。

## 帖子说明（表格原文）

一年前，硅谷已经开始反复讨论一组今天仍然没有过时的词：

high-agency、NPC、permanent underclass、996、taste、above or below the API。

当时，Claude Opus 4.1 还是 Anthropic 最强的模型，OpenAI 也才刚刚进入 GPT-5 时代。

一年之后，模型变了很多，但这些词背后的焦虑几乎没有消失：

当知识、代码和执行越来越便宜，什么才是一个人真正稀缺的能力？

你会成为调用 API 的人，还是 API 下面被重新分配的人？

所谓 taste，究竟是一种真正的判断力，还是 AI 时代重新包装过的 Idea Guy？

以及，当所有人都在强调 high-agency 时，我们到底是在描述一种能力，还是在创造一种新的身份焦虑？

重新读 Jasmine Sun 一年前写下的这篇文章，很像在翻一份来自未来的旧报纸。

很多当时只是 Twitter meme 的词，现在已经变成了真正的问题。
