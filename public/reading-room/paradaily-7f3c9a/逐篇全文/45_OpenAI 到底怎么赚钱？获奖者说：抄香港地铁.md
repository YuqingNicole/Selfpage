# 45. OpenAI 到底怎么赚钱？获奖者说：抄香港地铁

发布时间：2026-07-07 12:49:30 · [原帖](https://www.xiaohongshu.com/explore/6a4c855a0000000021023b5e?xsec_token=AB2pm_eeMV11GzjkxZ8Dv07TQOc3wXfMj4KXGdYyZg_WI=&xsec_source=pc_user) · 笔记 ID：6a4c855a0000000021023b5e

## 内容摘要

三篇获奖征文展示三种思考方法：把宏大愿景转为有预算与验收标准的工程方案；把一个前提推到极限检验后果；用香港地铁的“铁路＋物业”类比，寻找 AI 基础服务创造却未直接捕获的相邻资产价值。文章强调学习问题重构方式，而不是直接接受全部预测。

## 帖子说明（表格原文）

硅谷天使投资人，播客主理人 Dwarkesh Patel 悬赏 2 万美元征集“AI 大问题”的答案，收到 600+ 篇投稿，最终，三篇脱颖而出。

我们把三篇获奖作文逐句拆完后，发现选题即便是大相径庭（空气传播、国运、香港地铁），感叹三位作者才华横溢之外，我们发现让这三篇文章拿奖的逻辑都一模一样：元能力

[配图](../images/45_04.webp) · [来源图片](https://sns-img-bd.xhscdn.com/notes_pre_post/1040g3k8322ad5tr5nedg5od4llck1u1e9e8qc88?imageView2/format/jpg)

```text
一等奖：把一个商业问题，压缩
成一道工程题
Jassi Pannu 被问的是“如果让你运营
OpenAI 基金会，你会做什么”。这是个能
轻易写成万字空谈的商业文章命题。
她的第一句话就是答案：把基金会当成一个
国家级工程来运作，目标只有一个：那就是
终结呼吸道病原体的空气传播。
这么写？为什么？
拆开看，她做的是一次翻译：把“基金会该
做什么？”这种毫无边界的问题，写成“终结
空气传播”这种有预算、有时间表、有验收
标准的工程题。
```

```text
二等奖：用第一性原理，算一遍
国运
Ege Erdil 被问的是「不在AI供应链里的
中等国家该怎么办J。他的答案反直觉到冒
犯：什么都别做，并且顶住那些要求你“做

在他的推演里，AI会把“人力资本”这个元

这一项归零，国家竞争就退化成一道更原始

力、谁能更高效地使用它们。
于是，他给出的建议：给 AI自动化让路、
修掉那些阻碍它上岗的法律、把自己变成资
本最想去的「稳定之岛」。
```

```text
以上这只是他一个人的推演，价值观争议极
大，作者自己都承认这套方案“感觉很极
端”、几乎不可能被一个民主社会接受。
然而，它的价值不在于这套推演的现实可行

赢，而在别摔倒——在高波动的时代里，
「不犯错」本身就是一种复利。
他展示的能力，是顶着直觉的不安，把自己
```

```text
三等奖：用一个跨界类比，把问
题重新问一遍
Michael Li 处理的是那个被问了一万次的
问题：AI实验室到底怎么赚钱。
他没有正面回答，而是换了个问法。他说：
有这样一个行业，赚到第一美元前要先砸下
几十亿资本，核心服务贴着边际成本定价
—别想多了，我说的不是AI实验室，是
香港地铁。
这个类比的杀伤力在于，它把实验室怎么赚
钱这个看似全新的未解难题，还原成一个已
经被解决了长达45年的老问题。香港地铁
靠什么自负盈亏？不是靠票价，而是靠轨道
+物业的双线模型：铁路让沿线土地升值，
那公司就干脆自己拥有那些土地。
```

```text
票价是Hook，地置物业才是大鱼。
搬到 AI上，他的结论是：实验室别再纠结
API 什么时候盈利——API就是那条永远不
够赚钱的铁路。真正该做的，是现在就认出
那个会随 AI 基础设施升值的“铁路边的资
产”：可能是政府特许的独家部署权，也可
能是无法被蒸馏复制的独家数据，也可能是
占住分发与工作流的默认入口（比如操作系
统/浏览器层的深度集成、企业IT的标准套
件），或者被监管与信任结构保护的身份与
许可（KYC、认证、合规资质）。
他展示的能力，是用一个精确的类比，把陌
生问题映射到一个早有答案的旧问题上。
人类天然喜好从过去的故事寻找今天的解
法，好的类比不是修辞装饰，是解题工具。
```

```text
三篇文章都有一个共同点
```

```text
写在最后
如果你也想练这三种能力，其实对应着三个
可以马上做的动作：
下次遇到一个看似宏大的愿景，逼自己写出
它的预算和验收标准，去把它工程化；
下次接受一个大众共识之前，试着把它的某

论；
下次卡在一个「全新」的难题上，先间一
句：这道题，是不是别的行业早就解过了
—去找那个旧问题。
Dwarkesh 用2万美元筛人，但我们可以
偷师：值得学的不是这三篇本身写了什么，
而是它们背后的执笔者，各自是怎么想的。
```
